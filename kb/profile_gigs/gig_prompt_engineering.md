# Gig: I will prompt engineer ChatGPT, Claude, and Gemini for your dev workflow

## Tagline
Get a Prompt or System Message That Actually Works — ChatGPT, Claude, or Gemini

## Seller pitch
Generic prompts break the moment input gets messy, and a prompt that works well on one model often behaves differently on another. Builds and tests prompts for a client's specific model and use case — structured output, API integration, system prompts for internal tools — so what's delivered holds up in production, not just in a demo.

## What's delivered
- Written and tested system prompts for ChatGPT, Claude, or Gemini
- Prompts structured for reliable JSON / function-calling / tool-use output
- Simple custom GPTs, Claude Project instructions, or Gemini Gems
- Debugging of prompts giving inconsistent, wrong, or unstable output
- Porting a prompt that works on one model to another, adjusted for how that model actually behaves
- Documentation of the final prompt so the client's team can maintain it later

## How it works
1. Client describes their use case and which model they're using (or asks which one fits best), what the AI needs to do, and where it's breaking (if it's an existing prompt) or what they need it to do (if starting fresh)
2. Seller drafts the prompt and tests it against multiple real inputs, including edge cases, on the actual model
